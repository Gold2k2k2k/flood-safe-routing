# Frontend — Web App Bản Đồ Số

Thư mục dành cho mã nguồn giao diện Web App (gợi ý stack: React + Vite / Next.js + Leaflet hoặc MapLibre GL JS).

## Các module dự kiến
- **Live Flood Map:** Hiển thị bản đồ số đô thị (TP.HCM, Hà Nội), các marker camera giao thông và vùng cảnh báo đỏ khi phát hiện ngập.
- **Dynamic Rerouting UI:** Cho phép chọn điểm đi/điểm đến, mô phỏng lộ trình hiện tại và tự động vẽ lại lộ trình an toàn khi phát sinh điểm ngập mới.
- **Crowdsourcing Report Modal:** Form gửi ảnh hiện trường + GPS từ người dân/tài xế để AI chấm mức ngập.
- **Flood Heatmap View:** Chế độ bật/tắt bản đồ nhiệt tần suất ngập phục vụ phân tích hạ tầng đô thị.
